# Triage Labels

各 skill 用五个规范的 triage 角色交流。本文件把这些角色映射到本仓库 issue tracker 实际使用的 label 字符串。

| mattpocock/skills 中的 Label | 本 tracker 的 Label   | 含义                                     |
| ---------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`               | `needs-triage`       | 维护者需要评估该 issue                   |
| `needs-info`                 | `needs-info`         | 等待报告者补充信息                       |
| `ready-for-agent`            | `ready-for-agent`    | 规格完整,可交给 AFK agent               |
| `ready-for-human`             | `ready-for-human`    | 需要人来实现                             |
| `wontfix`                    | `wontfix`            | 不予处理                                 |

当 skill 提到某个角色(如"apply the AFK-ready triage label")时,使用上表对应的 label 字符串。

修改右列即可匹配你实际使用的词汇。
